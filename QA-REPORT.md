# QA report — Pixel Cat Club Deluxe 5.1

## Исправленные дефекты

1. Убрана повторная загрузка `app.js` и `deluxe.js`: теперь `auth-guard.js` загружает ядро, расширение и уведомления в одном согласованном порядке.
2. Исправлено сохранение, которое ссылалось на несуществующую переменную `saveNote`. Статус сохранения теперь обращается к `#save-note` с проверкой наличия элемента.
3. Подключены обработчики обеих кнопок поглаживания (`#pet-button`, `#pet-again`).
4. Удалён второй, дублирующий обработчик ежедневной награды.
5. Синхронизирован кошелёк монет между базовой игрой и расширением (город, кафе, компаньоны, сезонные награды и сундук).
6. Покупка компаньона теперь использует стабильный ID и не начисляет покупку повторно; после покупки кнопка убирается из списка доступных.
7. Сезонные награды используют ID события, а не текст кнопки, и могут быть получены только один раз.
8. Исправлена запись выбранного района города — сохраняется название района, а не подпись кнопки.
9. Сохранение мебели включает все добавленные предметы и восстанавливает их после повторной инициализации; добавлен единый pointer-based drag для мыши/сенсора.
10. Данные расширения включаются в основной снимок сохранения, отправляемый через событие `pixel-cat-save`, и используются для локального/опционального облачного восстановления.
11. Содержимое пользовательской подписи фотографии и текст воспоминаний выводятся как текст с HTML-экранированием; подпись `<img ...>` не создаёт DOM-элемент.
12. Исправлен полный сброс, чтобы он также сбрасывал расширение; при импорте нового сохранения устаревший отдельный снимок расширения больше не перекрывает импорт.
13. Service Worker получил новую версию кэша и включает `deluxe.js` в shell-файлы.
14. Авторская подпись `@Blooody11` сохранена в нижней части страницы и не перекрывает игровой интерфейс.

## Проверки, выполненные в этой сборке

- `node --check` для всех JavaScript-файлов.
- `manifest.webmanifest` прошёл JSON-проверку.
- Проверены 142 уникальных HTML ID (дубликатов нет на момент формирования отчёта).
- Chromium smoke-тест с реальным DOM, стилями и исходным JavaScript: отрисовка кота (35 SVG-прямоугольников), оба действия поглаживания, синхронизация кошелька, ежедневная награда, районы города, одноразовая сезонная награда, покупка компаньона, добавление мебели, сохранение фото-подписи, мини-игра и переключение всех 12 вкладок.
- В этом прогоне ошибок `pageerror` и console errors не зарегистрировано.
- Проверен сброс игрового состояния и расширения.
- Проверено восстановление после новой загрузки: добавленная мебель, альбом фотографий и баланс восстанавливаются из основного снимка сохранения.
- Проверены механики кафе (награда, анти-дублирование кликов, стоимость улучшения), одноразовое открытие сундука и сохранение характера котика.
- Проверен специально повреждённый снимок сохранения: приложение восстанавливает безопасные значения, некорректные записи котиков не ломают экран, а координаты мебели ограничиваются допустимым диапазоном.
- Статический аудит обработчиков не нашёл кнопок без связи с игровым действием или делегированным обработчиком; все ссылки на ID через `$()` существуют в HTML.

## Ограничения проверки

Chromium smoke-тест выполнялся на HTML/DOM с внедрёнными локальными файлами JavaScript и CSS; это проверка поведения игровых обработчиков, а не полное тестирование реального запуска через Live Server на всех браузерах. Внешняя интеграция Supabase, реальная push-доставка, разрешения уведомлений и офлайн-установка на разных устройствах не проверялись end-to-end. Для этих функций требуется конфигурация внешних сервисов и ручная проверка.
