# Pixel Cat Club Deluxe 5.1 — Quality Edition

Автор: **@Blooody11**

Pixel Cat Club — браузерная kawaii pixel-art игра. Проект сделан на обычных HTML, CSS и JavaScript и запускается из VS Code через Live Server. Сборка не требует npm или шага компиляции.

## Запуск

1. Распакуйте ZIP в отдельную папку.
2. Откройте эту папку в Visual Studio Code.
3. Откройте `index.html` и выберите **Go Live** (расширение Live Server).
4. Если игра уже была открыта, перезагрузите страницу с очисткой кэша (`Ctrl+F5`).

Для установки Service Worker, офлайн-кэша и уведомлений используйте localhost через Live Server или HTTPS — не открывайте `index.html` двойным щелчком через `file://`.

## Игровые системы

- Пиксельный кот с поглаживанием, мыслями, уровнем, опытом, достижениями и уходом.
- Скины, магазин аксессуаров и примерочная.
- Пять игровых миров, погода, смена дня и ночи, секреты.
- Мини-игры «Лови рыбок» и «Лови мышек» с очками и наградами.
- Город из шести районов, кошачье кафе, улучшения и репутация.
- Компаньоны, характер, дневник воспоминаний и сезонные награды.
- Комната с перетаскиваемой мебелью, фотоальбом и экспорт PNG-открытки.
- Единый кошелёк игровых монет между основной игрой, кафе, событиями и покупками компаньонов.
- Автосохранение в браузере, экспорт/импорт основного файла сохранения и сброс прогресса.
- Необязательная интеграция облачного сохранения через собственный проект Supabase.

## Сохранение и аккаунты

По умолчанию всё работает локально в браузере. Основной прогресс хранится в `localStorage` под ключом `pixelCatClubSave`, а расширение — в `pixelCatClubDeluxeSave`. При подключённом аккаунте используются отдельные ключи на пользователя, а данные расширения включаются в облачный снимок основного сохранения.

Облачный вход не включён автоматически. Для него нужно создать проект Supabase, настроить `supabase-config.js`, таблицы по `supabase/schema.sql` и провайдеры входа по документации Supabase. В репозитории нет секретных ключей; используйте только публичный anon key в клиенте, а секреты храните на серверной стороне.

## Уведомления и офлайн

Уведомления зависят от разрешения браузера. Для настоящих push-уведомлений дополнительно потребуются HTTPS, VAPID-ключи, таблицы Supabase и настроенная Edge Function. Без такой настройки остаются игровые функции и локальное сохранение; облачный push не обещается.

Service Worker использует версионированный кэш `pixel-cat-club-v5-1-shell` и включает `deluxe.js`, чтобы расширение было доступно при последующем офлайн-запуске после успешного кэширования.
